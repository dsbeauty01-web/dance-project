# Live Sales Playbook — the proven Chinese operator patterns

## The core insight

China runs thousands of profitable AI-host shopping streams daily. Their playbook is mature,
documented, and mostly transferable. The host is a LOOP with insertions, not a conversation —
90%+ of stream time is product presentation that is known BEFORE the stream starts.

## The 5-part script (五段式) — use for every product block

One product block = 5–8 minutes, structured:

1. **HOOK (0–30s):** grab in 3 seconds, name the pain, price ladder: original → live price → gift.
   Template: "Look at this! Normally ₪X — right now in the live only ₪Y, plus a free [gift]!"
2. **SELLING POINTS (30s–3min):** EXACTLY 3 points + one usage scenario + one testimonial.
   Compare to a named competitor ("18 hours more battery than X").
3. **INTERACTION (3–5min):** force engagement — "Type 1 for color A, 2 for color B!"
   Keyword auto-replies must cover 5 categories: shipping / sizing / discount / material / after-sales.
4. **URGENCY / 逼单 (5–7min):** stack the price (original → live → coupon → final), scarcity
   ("only X left"), push the link/CTA.
5. **CLOSE (30s):** preview the next product, "follow so you don't miss it."

## Rules that repeatedly separate winners from losers

- **Repeat key info 3×** — especially price. Viewers arrive mid-block; nothing lands once.
- **Segment stops between points.** Cramming all selling points into one breath = rookie failure.
- **Price band sweet spot ¥50–300 (~₪25–150), hard ceiling ~₪250 ($70).** Conversion collapses on
  expensive items — trust in a non-human host doesn't cover big tickets. Above the ceiling: add
  heavy trust signals + human takeover, or don't put it in the AI stream.
- **Time-of-day script variants:** morning = rational/functional framing; evening = emotional +
  limited-time. One operator reported +38% conversion from time-segmented scripts. Evening
  19:00–22:00 drives 60%+ of GMV; night hours are the AI host's structural edge (humans cost too
  much at 3am; AI converts the night owls — JD reported 8% conversion overnight, above daytime human).
- **Keyword answer branches: ≤15 seconds long, ≤3 layers deep** (product Q&A → price objection →
  after-sales). One operator: tuning 30 trigger words took interaction 1.2%→3.7%, conversion 2.1%→4.8%.
- **Interruption discipline:** at most one reply-insertion per ~30s; finish the current sentence
  before inserting — never cut the host mid-word.
- **Reply latency target: 10–40 seconds** from question to spoken answer. That's what human hosts
  take. Under 10s is unnecessary; over 40s reads as non-interactive (and on Chinese platforms,
  a ban signal).

## "Are you a robot?" handling

Lean INTO disclosure — the AI label is a trust anchor, not a weakness. One honest charming line,
move on. A real human handles text objections in parallel (customer-service in chat) while the
host runs the loop. NEVER deny being AI (illegal in most target markets — see live-platform-rules).

## Reported economics (vendor-reported, use directionally)

- Cost: AI host ≈ 1/10 of a human host. JD: conversion +30%, contributed GMV +62% growth in
  off-peak hours. Baidu: cost −80%, conversion +83%. 罗永浩's digital twin: ¥55M (~$7.65M) in ~7h.
- Chinese SMB package pricing: ~¥5,500/mo (~₪2,800) + ¥8,000 (~₪4,100) one-time custom avatar;
  commodity tiers as low as ¥199–999/mo. → Maya's ₪8–15K setup + ₪2–4K/mo is defensible ONLY as
  a DONE-FOR-YOU managed retainer (script ops, compliance, product selection, weekly review) —
  the raw software is commoditized/free. Sell operations + compliance, never the avatar.

## Documented failure modes (avoid)

- Lip desync, low-res upscaled video, green-edge halos → viewers bounce, platforms flag.
- Recorded-video-masquerading-as-live with slow Q&A → ban.
- Fully-unattended streaming → ban (China) / policy violation (most platforms).
- Single script looping unchanged for hours → flagged as low-quality; rotate 3 script sets,
  switch every ~2 hours.
- Absolute claims ("100% effective", "cheapest ever") and regulated categories (supplements,
  medical, finance, weight loss) → fastest route to a cut stream.
