🧪 NOVA MANIPULATION TESTS · INDEX

4 focused tests

Each test isolates ONE question about whether/how we can manipulate Nova through cues. Run them in order. After all 4 you'll know what's actually possible — no more guessing.

Each test creates its OWN Runway session. Each session = 5-min Runway cap and uses credits. Best to do all 4 within one ~20 minute window so you don't burn extra cold-starts.
▶ Test 1 — Cues
Does injecting text into Nova's mic make her face change?
7 buttons with different texts. Click each, watch her face. If face stays same → mic injection is dead end. If face changes → we have a lever.
▶ Test 2 — Rate
Can we fire micros rapidly without breaking her?
Slider sets interval (1-6s). Auto-fires micros. Does she keep up? Overlap? Get confused? Tells us the upper rate limit.
▶ Test 3 — Styling
Does word styling actually change her face?
Same word, different punctuation/caps. "yes" vs "YES!" vs "yes..." vs "yesss". Compare faces side-by-side.
▶ Test 4 — startScript
Does the startScript we send Runway control her opening?
Type a startScript, boot Nova, see what she actually says first. If she ignores → startScript is for show. If she says it → we can stage entrances.
